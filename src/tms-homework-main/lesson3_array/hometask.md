# Домашнее задание: Одномерные массивы

> **Требования к оформлению:**
> 1. Для каждого задания создавайте отдельный класс с понятным именем (например, `ArraySearch`, `RemoveElement`, `BubbleSort`).
> 2. Форматируйте код перед отправкой (`Ctrl + Alt + L` в IntelliJ IDEA).
> 3. Именуйте переменные по стандарту **lowerCamelCase**, классы — **UpperCamelCase**.

---

## Основное задание

### Задание 0
Создайте массив целых чисел. Напишите программу, которая выводит сообщение о том, входит ли заданное число в массив или нет.
* **Условие:** Число для поиска задается с консоли (класс `Scanner`).

### Задание 1
Создайте массив целых чисел. Удалите все вхождения заданного числа из массива.
* **Условия:**
    * Число задается с консоли (класс `Scanner`).
    * Если такого числа нет — выведите сообщение об этом.
    * В результате должен быть сформирован **новый массив** без указанного числа.

### Задание 2
Создайте и заполните массив случайными числами. Выведите максимальное, минимальное и среднее значение.
* **Условия:**
    * Для генерации случайных чисел используйте метод `Math.random()`.
    * Размер массива должен задаваться с консоли.

### Задание 3
Создайте 2 массива из 5 чисел.
* **Условия:**
    * Выведите массивы на консоль в двух отдельных строках.
    * Посчитайте среднее арифметическое элементов каждого массива.
    * Сообщите, для какого из массивов это значение оказалось больше (либо сообщите, что их средние арифметические равны).

## Дополнительное задание

### Задание 4
Создайте массив из $n$ случайных целых чисел и выведите его на экран.
* **Условия:**
    * Размер массива $n$ задается с консоли и должен удовлетворять условию: $5 < n \le 10$.
    * Если пользователь ввел число, не удовлетворяющее условию — выведите сообщение об ошибке и **заставьте пользователя повторить ввод**.
    * Создайте второй массив только из чётных элементов первого массива (если они там есть) и выведите его на экран.

### Задание 5
Создайте и заполните массив.
* **Условия:**
    * Выведите массив на экран в строку.
    * Замените каждый элемент с нечётным индексом на ноль.
    * Снова выведите обновленный массив на экран на отдельной строке.

### Задание 6
Создайте массив строк. Заполните его произвольными именами людей.
* **Условия:**
    * Отсортируйте массив.
    * Результат выведите на консоль.

### Задание 7
Реализуйте алгоритм сортировки пузырьком (Bubble Sort) для массива.
